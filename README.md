# EverydayQuest

EverydayQuest is an Android application developed for the Mobile Systems course.

The application turns physical activities into daily quests.

## Features

- Daily Walk, Explore and Move quests
- GPS-based distance tracking
- Accelerometer-based movement detection
- XP and level system
- Daily completion bonus
- Quest history using RecyclerView
- CustomView for quest progress
- Local storage using SharedPreferences
- Activity-to-Activity data transfer using Intents

## Technologies

- Kotlin
- Android
- Android Studio
- GPS / Location
- Accelerometer
- RecyclerView
- SharedPreferences
